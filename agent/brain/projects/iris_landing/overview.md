# Project Overview

The Iris Landing Page project is a full-stack application designed to provide a user-friendly interface for potential users to join a waitlist. It utilizes a **Next.js** frontend for dynamic rendering and a **FastAPI** backend for handling API requests.

## Key Features
- User interaction components such as forms for email submission.
- A visually appealing landing page that highlights the purpose of the application.

## Source Evidence
- The project uses Next.js for the frontend and FastAPI for the backend.
- It includes components for user interaction like forms and headers.
