# Use Next.js for Frontend

This document records the decision to use Next.js for the frontend of the Iris Landing Page.

Next.js provides a robust framework for building the frontend. It allows for server-side rendering and static site generation.

## Source Evidence
- Next.js provides a robust framework for building the frontend.
