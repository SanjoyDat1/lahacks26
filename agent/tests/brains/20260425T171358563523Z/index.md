# LA Hacks Operations Brain

This folder constitutes the structured operational brain for LA Hacks. It is designed to be readable by humans, efficient for LLM lookup, and to serve as a central, auditable source of truth for event logistics and planning.

Treat this file as the required entry point. Every important generated file should be reachable from this page directly.

## Read Order For Agents

1.  Read [Project Summary](summaries/project_summary.md) for the shortest useful context.
2.  Review [Decision Log](decisions/decision_log.md) for confirmed operational choices and rationale.
3.  Consult [Constraints](context/constraints.md) for boundaries and non-negotiable requirements.
4.  Check [Open Questions](context/open_questions.md) for unresolved operational items and areas needing clarification.
5.  Review [Slack Integration](integrations/slack.md) and [Meetings Integration](integrations/meetings.md) for details on how communication and decisions are captured.

## Purpose of this Brain

This brain serves as the central repository for operational knowledge, durable decisions, constraints, and open questions for LA Hacks. Its primary goal is to provide a single, auditable source of truth for event logistics, ensuring continuity and clarity across various teams (e.g., platform, ops, finance).

It distills critical information from diverse communication channels like Slack, emails, meeting transcripts, and review notes to support smooth event execution, especially leading up to and during demo day. Key operational areas covered include registration, reimbursement, Devpost backups, incident command protocols, and communication guidelines.
